# Libft

A library of various useful function. 

## Description

this goal of this project was to make various functions that will be useful for the curriculum. the first few function are recreated from the libc, that will give the same output as the orignal. there are also additional functions that were not included in libc or that exist in a diffrent form. 

## Instructions

in this project you can use the Makefile to compile and execute the Libft.

### executing program
```
<!-- executes the whole program -->
make all
<!-- remmoves all object files -->
make clean
<!-- removes all files created by the program -->
make fclean
<!-- removes all files created by the program and re executes the program -->
make re
```
